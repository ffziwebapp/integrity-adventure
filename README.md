# Integrity Adventure

Kuis eliminasi 9 Nilai Integritas KPK untuk dimainkan bersama lewat Zoom.

| Halaman | Untuk | Alamat |
|---|---|---|
| `index.html` | Peserta (HP) | `…/index.html?r=KODE` |
| `panggung.html` | Layar yang dibagikan di Zoom | dibuka dari panel pemandu |
| `pemandu.html` | Panel kendali pemandu | `…/pemandu.html` |

Folder ini adalah akar repository: `index.html` harus berada di tingkat teratas.

Bank soal (berkas CSV berisi kunci jawaban) **jangan** dimasukkan ke repository ini.
Muat lewat panel pemandu; kuncinya tersimpan di database dan hanya bisa dibaca akun pemandu.

Menambahkan `&uji` (atau `?uji`) pada alamat menjalankan mode latihan tanpa internet
yang menyimpan data di peramban itu saja.

Tampilan memakai huruf Baloo 2 dan Nunito yang disimpan di folder `fonts/` (lisensi SIL OFL),
jadi halaman tidak bergantung pada Google Fonts.
